# 🌐 Portofolio - Muhammad Rizqi Febrian

Portofolio web pribadi **Muhammad Rizqi Febrian**, mahasiswa S1 **Ilmu Komputer** di **Universitas Muhammadiyah Kudus (UMKU)**. Berisi informasi profil, riwayat pengalaman organisasi & kepanitiaan, keahlian teknis, serta showcase proyek Website dan Desain Grafis.

---

## ✨ Fitur Utama
- **Desain Modern & Responsif**: Mengusung konsep *dark mode* dengan sentuhan *glassmorphism* dan animasi halus.
- **Hero Profile**: Menampilkan foto profil dengan *glow ring*, *floating badge*, serta bio singkat.
- **Filter Pengalaman**: Memisahkan rekam jejak antara kegiatan **Organisasi** dan **Kepanitiaan**.
- **Filter Portofolio Proyek**: Kategori proyek **Website (Web Development)** dan **Desain Grafis** dengan modal preview (lightbox).
- **Keahlian & Tools**: Visualisasi progress bar untuk Web Development, Desain Grafis, dan Soft Skills.
- **Form Kontak Terintegrasi**: Formulir interaktif yang langsung terhubung ke WhatsApp.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5** (Semantik)
- **CSS3** (Custom Properties, Flexbox, Grid, Glassmorphism, Keyframes Animation)
- **JavaScript (ES6+)** (DOM Manipulation, Scrollspy, Interactive Filters, Lightbox Modal)
- **Font Awesome 6** & **Google Fonts (Plus Jakarta Sans & JetBrains Mono)**

## 🚀 Cara Menjalankan Secara Lokal
1. Clone repositori ini:
   ```bash
   git clone https://github.com/MrfNayr/portofolio.git
   ```
2. Masuk ke direktori:
   ```bash
   cd portofolio
   ```
3. Buka berkas `index.html` di browser pilihan Anda (klik ganda atau gunakan ekstensi Live Server).
